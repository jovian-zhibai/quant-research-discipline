# 四道闸门与自欺清单

## 闸门一：成本后为正

- 必须扣除：手续费、点差、滑点、funding、税
- 报告里同时给"含成本"和"不含成本"两行，只有含成本那行算结论
- 不含成本的回测数字，一律标注为"毛收益参考，不可作为决策依据"

## 闸门二：样本外不衰减

- 判据：样本外净收益 / 样本内净收益 ≥ **50%**
- 低于 50% 通常是：参数过拟合、市场结构变化、或样本外时段太短
- 必须做 walk-forward（滚动前进），不能一次性切分
- 重叠标签（同一事件影响多期）要留 purge/embargo，否则信息泄漏，样本外数字虚高

## 闸门三：试验次数已记账

**这是最容易被跳过、也最致命的一条。**

零信号下，试 N 次得到的最大 Sharpe 期望约为 `√(2 ln N)`：

| 试验次数 N | 纯噪声下的最大 Sharpe（近似） |
|---|---|
| 10 | 2.15 |
| 30 | 2.61 |
| 100 | 3.03 |
| 156（一年每周 3 个） | 3.18 |
| 300 | 3.38 |

**读法**：如果你试了 30 个参数组合，看到最好的那个 Sharpe 2.6，那还没超过噪声线——它是抽样最大值，不是能力。
试了 156 次看到 3.0 也一样。

所以：
- 每改一次参数、每换一次窗口、每试一个新标的，都要记一条 trial
- 不记账的 Sharpe 视为无效
- `scripts/quant_check.py trial stats` 会打印当前 N 下的噪声线，直接比对

## 闸门四：第三方可复现

必须给出：
1. 数据来源与版本（哪家交易所、哪个接口、取数时间）
2. 完整参数
3. 成本假设
4. 代码或等价复现步骤

**做不到这一条的结论，只能叫"我的观察"，不能叫"策略有效"。**
尤其注意：模拟盘的 P&L 账本是自证的——它由系统自己记录，没有外部核验，不能作为"已证明"的证据。

## 常见自欺清单（逐条自查）

1. **把模拟盘赚钱当成策略有效**。模拟盘只验执行链路，不验 alpha。
2. **回测用中间价成交**。真实成交在对手价，加上滑点。
3. **只算手续费，不算 funding 和滑点**。永续长持尤其致命。
4. **试了很多组参数，只报告最好的那组**。不记 trial，等于把抽样最大值当发现。
5. **样本外时段太短**。三个月跑出来的"稳定性"是噪声。
6. **重叠标签直接切分**。没做 purge 的 walk-forward，样本外一样泄漏。
7. **用"逻辑通顺"替代"数据支持"**。故事讲得越顺，越要警惕。
8. **看到一次大赚就加仓**。单次结果不构成证据，这是纪律问题不是策略问题。
9. **把"这次不一样"当成理由**。市场结构变化要用数据证明，不是用叙事证明。
10. **凑数冲动**。只有一个策略过闸门时，想把第二个的分数抬一抬——最需要抵抗的就是这个。

## 报告收尾必带

- 四道闸门的逐条结论（过 / 未过 / 未验证）
- 数据缺口清单（哪些数据拿不到，因此哪些结论不成立）
- 一个明确的下一步动作（继续观察 / 否决 / 转 paper）
- 若否决：写进 `graveyard.md` 并注明理由，一个月内不得重启
